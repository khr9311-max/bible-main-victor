2. 접근 권한과 처리하는 정보

프로그램은 YouTube API Services를 사용합니다. 채널 소유자가 Google에서 로그인하고 동의하면 YouTube Data API와 YouTube Analytics API의 읽기 전용 권한을 사용합니다. 현재 권한은 youtube.readonly와 yt-analytics.readonly입니다.

  • 채널 ID·이름, 영상 ID·제목·게시일·길이·공개 상태 등의 채널·영상 정보
  • 조회수, 참여 조회수, 시청시간·시청지속률, 구독 증감, 좋아요·댓글·공유의 수와 유입 유형 등 집계 통계
  • 접근 권한 유지에 필요한 OAuth 액세스 토큰과 갱신 토큰

영상 목록을 확인하는 과정에서 비공개 영상의 정보도 일시적으로 받을 수 있습니다. 현재 보고서의 개별 영상 목록은 공개 영상으로 제한하지만, 채널 전체 통계에는 비공개 영상의 활동이 포함될 수 있습니다. 시청자 개인의 신원이나 댓글 내용은 현재 분석 코드에서 요청하지 않습니다. Google 비밀번호는 프로그램에 입력하거나 저장하지 않습니다.

문의나 삭제 요청을 보내면 회신용 이메일 주소, 문의 내용 및 대상 채널 정보를 요청 처리에 사용합니다. 비밀번호나 인증 토큰은 요청하지 않습니다.

3. 사용과 외부 처리

채널 정보와 통계는 영상별·기간별 성과 비교, 시청 흐름 확인, 콘텐츠 기획 검토에 사용합니다. 광고 타기팅이나 데이터 판매를 목적으로 사용하지 않습니다.

운영자가 AI 분석을 요청하면 필요한 채널 정보와 집계 통계가 OpenAI Codex에서 처리될 수 있습니다. 별도의 영상 검토를 요청하는 경우 운영자가 제공한 영상·음성·썸네일·대본을 Google Gemini에서 처리할 수 있습니다. Google API로 받은 비공개 통계와 제작용 영상 자료는 구분하며, 요청한 분석에 필요한 범위로 전달합니다.

외부 서비스의 처리·보관은 해당 서비스 및 계정 설정에 따릅니다. 이 프로그램은 외부 서비스의 모든 사본이 즉시 삭제되거나 AI 학습에 이용되지 않는다고 보장하지 않습니다. 새로운 목적이나 외부 제공 범위를 추가할 때에는 먼저 알리고 동의를 받습니다.

4. 저장과 보관 관리

OAuth 자격증명과 JSON·CSV·Markdown 형식의 통계 보고서는 운영자의 작업 컴퓨터에 파일로 저장합니다. 토큰 파일은 소스 관리에서 제외하며, 토큰이나 비공개 통계 원자료를 이 공개 안내 사이트에 게시하지 않습니다. 프로그램 자체에는 저장 파일의 암호화 기능이 없으므로 기기의 접근 권한과 보안 설정으로 관리합니다.

자동 점검·삭제 기능은 없습니다. 아래 기준은 운영자가 수동으로 이행하는 보관·삭제 정책입니다.

  • 승인받은 Analytics·통계를 30일 넘게 보관할 경우, 30일마다 접근 승인 유효성과 원본 영상의 삭제 여부를 확인합니다.
  • 그 밖의 저장된 채널·영상 메타데이터는 수집 후 30일 이내에 다시 조회해 갱신하거나 삭제합니다.
  • 접근 승인이 취소되거나 분석 목적이 끝난 자료는 관련 로컬 파일·복사본·백업을 확인해 삭제합니다.

자료를 다른 저장소에 복사한 경우에도 같은 관리 기준을 적용합니다. 오래된 보고서가 새 조회만으로 자동 갱신되거나 삭제되지는 않습니다. 문의 이메일은 요청 처리에 필요한 동안 보관하고, 처리가 끝나 더 보관할 필요가 없으면 삭제합니다.

5. 연결 해제와 삭제 요청

Google 계정의 연결된 서비스 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 이 조치는 이후의 API 접근을 제한하지만, 이미 저장된 보고서를 자동 삭제하지는 않습니다.

저장 자료를 삭제하려면 운영자에게 데이터 삭제 요청을 보내 주세요. 요청 내용에는 대상 채널과 삭제할 자료 범위만 적고, 비밀번호나 인증 토큰은 보내지 마세요. 운영자는 삭제 요청을 받은 날부터 지체 없이, 늦어도 7일 이내에 로컬 자료와 관리하는 복사본·백업에서 관련 데이터를 삭제합니다. Google 계정 관리 화면에서 권한을 철회한 경우에도 철회한 날부터 지체 없이, 늦어도 30일 이내에 관련 데이터를 삭제합니다.

외부 AI 서비스에 분석 자료를 전달한 경우 해당 대화·파일의 삭제 방법과 처리 범위를 함께 확인합니다. 외부 서비스가 자체 정책에 따라 보관하는 기록은 해당 서비스의 삭제·보관 정책이 적용됩니다. 이 프로그램의 자료를 삭제해도 YouTube에 있는 원본 영상은 삭제되지 않습니다.

6. 안내 사이트와 외부 링크

이 두 안내 페이지에는 방문 분석 스크립트, 광고 추적기, 입력 양식, Google 로그인 기능을 넣지 않았습니다. 호스팅 업체 Vercel은 페이지 제공과 보안을 위해 IP 주소·접속 시각·브라우저 정보 등의 접속 기록을 처리할 수 있습니다. 자세한 내용은 Vercel 개인정보 안내를 참고하세요.

외부 링크를 열면 해당 서비스의 정책이 적용됩니다. Google의 처리는 Google 개인정보처리방침, OpenAI의 처리는 OpenAI 개인정보처리방침에서 확인할 수 있습니다.

7. 변경 안내와 관련 기준

처리 목적·정보 범위·제공 대상이 달라지면 이 문서와 프로그램의 안내를 갱신하고 필요한 동의를 먼저 받습니다. 이 프로그램은 Google 또는 YouTube가 운영하거나 공식 인증한 서비스라고 주장하지 않습니다.

Google API Services User Data Policy 및 Limited Use 요구사항과 YouTube API Services 개발자 정책을 데이터 관리 기준으로 사용합니다. 프로그램을 이용할 때에는 YouTube 서비스 약관도 적용됩니다.
